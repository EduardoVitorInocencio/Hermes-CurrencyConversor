# HERMES — checklist de release

- [x] Lint, typecheck, testes unitários, build e E2E executados.
- [x] Conversor, histórico, filtros, paginação e CSV implementados sem dados de produção inventados.
- [x] Responsividade e landmarks verificados nos viewports de referência.
- [x] Collection Postman e limitações da API documentadas.
- [x] README e TECH_SPEC atualizados.
- [ ] Pull Request revisado e integrado — não autorizado pelo usuário nesta execução.
- [ ] Publicação em `main` — não autorizada; trabalho permanece na branch `dev`.

Conclusão: o checkout local está pronto para revisão, mas não deve ser chamado de release integrada enquanto PR/merge permanecerem pendentes.
