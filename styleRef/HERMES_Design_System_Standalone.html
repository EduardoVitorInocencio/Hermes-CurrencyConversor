03 / Dimensions

Espaçamento / base de 4 px

Unidade de referência: 4 px (0,25 rem com raiz de 16 px). Use os mesmos valores em padding, gap e margens; preserve 10 e 28 px como exceções existentes no Figma.

Receitas de composição: controle padding-inline:16px + padding-block:12px; card padding:24px; entre cards gap:16px; entre seções gap:32px.
04 / Dimensions

Bordas, raios e elevação

Raios oficiais: 6, 8, 12, 16 e 999 px. Bordas finas e sem sombras por padrão. As antigas medidas 7, 9, 13 e 15 px foram normalizadas nas principais áreas, com exceções restantes a revisar.

Border: 1px solid var(--color-border-default) em cards e painéis. Inputs usam --color-border-control. Não existe Effect Style de sombra no arquivo atual.

07 / Responsive

Layout / do mobile ao desktop

A ordem semântica é mercado → conversor → evolução → histórico. O CSS desta referência adapta os exemplos, mas isso não comprova que todas as telas do protótipo Figma estejam responsivas.

MOBILE FIRST

390 px · referência visual

padding-inline: 16px · grades de duas colunas nos cartões; conversor e filtros empilhados em telas pequenas; conteúdo essencial visível, sem scroll horizontal da página.

Cabeçalho testado: 375 / 390 / 430 px
DESKTOP · LG ≥ 1024

1440 px · referência visual

Sidebar atual: 248 px (256 px é uma referência de grid). Quatro cards no overview; maior densidade de dados mantendo a mesma paleta, componentes e hierarquia.

1280 px e tablet: validação pendente no Figma
Breakpoints de implementação sugeridos: Mobile 375–430 px, tablet 768 px, desktop ≥1024 px e desktop grande 1280–1440 px. São regras de CSS desta página, e não novos modos de variável nem telas automaticamente criadas no Figma.

Developer handoff

Base de implementação para Codex

Use o bloco :root do início deste arquivo como fonte dos tokens. O HTML possui CSS e JavaScript internos e funciona com uma conexão de rede desligada.

Recomendação de integração: no React + JavaScript + Vite + CSS Modules, extraia o bloco CSS :root para src/styles/tokens.css e importe uma vez em main.jsx. Converta os exemplos em componentes JSX sem usar o JavaScript demonstrativo como lógica de produção. Substitua os valores de exemplo pela API Frankfurter e trate loading, erro, empty state e acesso por teclado.
